Wolf Vitae - Criador de Currículos Profissionais

Versão 2.0
Desenvolvido por: @jottap_62
Projeto: Wolf-edit

Descrição

Wolf Vitae é um criador de currículos interativo em Python que gera arquivos PDF personalizados com estilos modernos e profissionais. Ideal para quem deseja criar, editar e personalizar currículos diretamente no terminal, com suporte a foto, marca d’água, formatação elegante e validação de dados.

Funcionalidades

Interface interativa no terminal

Vários modelos de currículo com estilos e cores personalizáveis

Adição de foto com opção de tamanho e formato (quadrada/redonda)

Inclusão de marca d'água (imagem ou texto)

Criação e edição de currículos existentes

Geração de PDF com layout profissional

Seção opcional de ISSP (Informações Sociais e Socioprofissionais)

Validação de e-mail, telefone e datas

Salvamento automático dos dados em JSON para edição futura


Requisitos

Python 3.x

Bibliotecas:

reportlab

Pillow



Você pode instalar as dependências com:

pip install reportlab Pillow

Como usar

Execute o script no terminal:

python3 wolf-vitae.py

Menu Principal

1. Criar novo currículo: preencha os campos solicitados e gere o PDF.


2. Abrir pasta de currículos: abre a pasta onde os PDFs são salvos.


3. Sobre: exibe informações do projeto.


4. Editar layout de currículo existente: edite modelos já salvos (.json).


5. Sair: encerra o programa.



Os currículos são salvos por padrão em:
/sdcard/wolf_documentos
